\# WorkSphere



\### Role-Based Project Management and Team Collaboration System



\## Project Overview



WorkSphere is a web-based project management and team collaboration system developed using Django. It provides a centralized platform for managing projects, assigning tasks, monitoring progress and improving communication between team members.



The system provides role-based access for Administrators, Managers, Employees and Clients.



\## Key Features



\- User Authentication and Authorization

\- Role-Based Access Control

\- Interactive Dashboard

\- Project Management

\- Task Assignment and Tracking

\- Employee Management

\- Team Management

\- Meeting Management

\- File Sharing

\- Project Discussions

\- Notifications

\- Department Management

\- Audit Logs

\- Client Project Progress Monitoring



\## User Roles



| Role | Responsibilities |

|---|---|

| Administrator | Manage users, departments and system operations |

| Manager | Manage projects, assign tasks and monitor progress |

| Employee | View assigned tasks and submit completed work |

| Client | View assigned projects and monitor project progress |

\## System Architecture



WorkSphere follows Django's Model-View-Template (MVT) architecture.



\- \*\*Model:\*\* Manages database operations and application data.

\- \*\*View:\*\* Handles business logic and user requests.

\- \*\*Template:\*\* Displays the user interface.



\## Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/madhvipatel-dev/WorkSphere.git

cd WorkSphere

```



\### 2. Create a virtual environment



```bash

python -m venv venv

```



\### 3. Activate the virtual environment (Windows)



```powershell

.\\venv\\Scripts\\Activate.ps1

```



\### 4. Install dependencies



```bash

python -m pip install -r requirements.txt

```



\### 5. Configure environment variables



Configure the required Django settings and environment variables for your local environment.



\### 6. Apply database migrations



```bash

python manage.py migrate

```



\### 7. Create an administrator account



```bash

python manage.py createsuperuser

```



\### 8. Run the development server



```bash

python manage.py runserver

```



Open http://127.0.0.1:8000/ in your browser.
